# The Candidate 

The candidate is a simple VR application that focues on simulating different job interviews.

The project is in collaboration of NAV where the goal is for people to use it in practicing before job interviews and become mmore secure and comfortable.

The project is stiched together by the use of many already existing open source project out there, like

- The makehuman community for creation of humans
- Ulipsync for the lip syncing
- Poly haven for assets
